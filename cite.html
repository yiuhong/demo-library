How to cite

Cite the library as a whole. This is Teaching materials library by Yiu Hong Ko, version 0.1.0, last updated 29 October 2026.

APA 7

Ko, Y. H. (2026). Teaching materials library (Version 0.1.0). https://yiuhong.github.io/demo-library/

The title is in APA sentence case. The version identifies this release.

BibTeX

@misc{ko2026teachingmaterials,
  author  = {Ko, Yiu Hong},
  title   = {{Teaching Materials Library}},
  year    = {2026},
  version = {0.1.0},
  url     = {https://yiuhong.github.io/demo-library/},
  note    = {Version 0.1.0, last updated 29 October 2026}
}
