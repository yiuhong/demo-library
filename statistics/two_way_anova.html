Interactive Two-Way ANOVA (2 × 2 Factorial Design)

Two-Way ANOVA simultaneously tests three hypotheses: the main effect of Factor A (Group: 1, 2), the main effect of Factor B (Gender: Female, Male), and their Interaction (Group × Gender)—whether the effect of Group depends on Gender.

Factor A: Group (kA = 2) Factor B: Gender (kB = 2)

Two-Way ANOVA Omnibus Table & Variance Partitioning

SSTotal = SSGroup + SSGender + SSInteraction + SSWithin
0% Total Variance (SSTotal) is partitioned into these 4 components 100%
1. Main Effect of Group (Factor A)
SSA = n·kB Σ (x̄i· − x̄··)²  |  dfA = kA − 1
2. Main Effect of Gender (Factor B)
SSB = n·kA Σ (x̄·j − x̄··)²  |  dfB = kB − 1
3. Interaction Effect (Group × Gender)
SSAB = n ΣΣ (x̄ij − x̄i· − x̄·j + x̄··)²  |  dfAB = (kA−1)(kB−1)
How to Calculate SSInteraction ▼

It measures the "surprise" in each cell beyond the basic main effects:

  • 1. Expected Mean: Add the Group and Gender means, then subtract the Grand Mean (to avoid double-counting the baseline). Expected = x̄i· + x̄·j - x̄
  • 2. Deviation: Subtract this Expected mean from the Actual cell mean (x̄ij) to find the interaction "surprise."
  • 3. Sum Across Cells: Square these deviations, multiply by the people per cell (n), and sum them up across all cells (ΣΣ). SSAB = n ΣΣ (x̄ij - Expected)²
4. Within-Cells Error (Residual)
SSW = ΣΣΣ (yijk − x̄ij)²  |  dfW = N − kAkB
Source of Variation SS df MS (SS / df) F (MS / MSW) p-value Decision (α = .05)
